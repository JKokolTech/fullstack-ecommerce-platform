# Shopify E-Commerce Storefront

Full-stack e-commerce web application with authentication, product management, and payments.

🔗 Live Store: https://pawparallel.com

## Project Description
A production e-commerce storefront built on Shopify with custom theme modifications and client-side enhancements.

## Engineering Focus
- Theme customization using Liquid templates
- Modular layout using sections and snippets
- Custom JavaScript for improved UX
- Performance and responsiveness considerations
- Real-world e-commerce constraints

## Tech Stack
- Shopify
- Liquid
- JavaScript (ES6)
- HTML / CSS

## Why No Source Code?
Shopify manages store infrastructure and backend services.  
This repository documents the project and provides a live demonstration of the implemented solution.
